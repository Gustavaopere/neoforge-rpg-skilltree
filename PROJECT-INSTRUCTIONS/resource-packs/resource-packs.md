# Índice mestre — Resource Packs

Este índice é incremental e acompanha a auditoria de `PROJECT-INSTRUCTIONS/resource-packs/`.

Como o repositório não contém um inventário físico ordinal atual de `resourcepacks/`, a coluna **Nº** representa a **ordem determinística do catálogo auditado**, usada pelos lotes de auditoria (#1–#10, #11–#20, #21–#30 etc.). Ela não deve ser interpretada como load order nem como posição física do ZIP no diretório.

A coluna **Arquivo ZIP** reproduz a evidência física/canônica registrada no dossier. Quando o projeto não publica versão semântica própria, isso permanece explícito em vez de fabricar uma versão.

A organização estrutural usa as categorias temáticas atuais exibidas pelo projeto correto no CurseForge, em ordem alfabética e separadas por ` + `. A classe `Resource Packs` e classificações puramente técnicas de resolução não entram no nome da pasta. Quando o projeto confirmado não expõe nenhuma categoria temática além dessas classificações técnicas, usa-se a pasta estrutural explícita `Sem categoria temática no CurseForge`; ela não é tratada como categoria oficial.
