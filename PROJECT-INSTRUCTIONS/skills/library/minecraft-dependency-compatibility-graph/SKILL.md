# Minecraft Dependency and Compatibility Graph

Use para mapear dependências obrigatórias/opcionais, libraries, addons de compatibilidade, version ranges, forks/ports e relações entre mods.

Construa nós e relações com evidência: requires, optional, embeds, bridges, replaces, conflicts-with e unknown. Não transforme correlação em dependência. Para o modpack, a modlist física atual é authority de presença/versão.
