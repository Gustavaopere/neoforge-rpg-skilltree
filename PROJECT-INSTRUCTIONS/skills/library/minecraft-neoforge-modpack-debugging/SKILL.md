# Minecraft NeoForge Modpack Debugging

Use para crashes, hangs, incompatibilidades, dependências, mixins, registries, configs e escolha da correção menos destrutiva em Minecraft 1.21.1 NeoForge.

Workflow: estabeleça cronologia → classifique a falha → construa cadeia causal → confira mudanças recentes → investigue compatibilidade → formule uma hipótese por vez → aplique a menor correção → valide. Não remova mods em massa sem evidência. Se o culpado não puder ser isolado por logs/JAR, roteie para `minecraft-modpack-bisect`.
