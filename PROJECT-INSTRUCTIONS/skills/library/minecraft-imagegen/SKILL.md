# Minecraft Image Generation

Use para pack icons, promo art, concept textures, thumbnails, banners, UI mockups e folhas de referência.

Defina uso, asset type, contexto visual, composição, palette, constraints e o que deve permanecer inalterado. Para modelos/texturas de gameplay, trate image generation como concept/look-dev: não assuma que a saída já possui UV, tileability, pixel density, rig ou integração correta. O handoff final é feito pelas skills específicas de asset/model/resource pack.
