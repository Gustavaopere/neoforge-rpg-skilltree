# Hardening Plan — Compatibility Matrix

**Goal:** definir exatamente quais combinações de mods fazem parte do suporte de release.

- [ ] Core sem mods opcionais.
- [ ] Cada integração isolada.
- [ ] Combinações críticas Iron's + Ars, Epic Fight + projectile/magic, morphs + classes.
- [ ] Create/AE2/Oritech conforme nível de integração decidido.
- [ ] Registrar conflitos conhecidos e versões testadas.

**Acceptance:** compatibilidade publicada corresponde a combinações realmente testadas.
