# World Scaling Plan — Relevant Player Level

**Goal:** escolher uma referência de progressão coerente para cada encontro, especialmente em multiplayer.

- [ ] Definir busca espacial/party de jogadores relevantes.
- [ ] Tratar nenhum jogador, vários jogadores e grande disparidade de níveis.
- [ ] Evitar usar jogador distante/aleatório como referência.
- [ ] Implementar cache com invalidação apropriada.
- [ ] Medir custo para impedir scans caros por tick.

**Acceptance:** a mesma situação multiplayer resolve nível relevante de forma previsível e com custo bounded.
