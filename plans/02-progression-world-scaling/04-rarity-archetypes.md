# World Scaling Plan — Rarity and Archetypes

**Goal:** criar variedade de encontro sem depender apenas de multiplicadores lineares.

- [ ] Definir quando raridade/arquetipagem é rolada.
- [ ] Persistir seleção para impedir reroll em reload.
- [ ] Aplicar modifiers idempotentes.
- [ ] Separar raridade de arquétipo para permitir combinações controladas.
- [ ] Definir tratamento específico/fallback para bosses.

**Acceptance:** uma entidade não muda de raridade ao recarregar e cada arquétipo modifica comportamento/atributos de forma rastreável.
