# MINING — Transmutation Perks

- **Range reservado:** `T7000–T7999`
- **Quota:** `N_transmutation` nós-base
- **Filhos `.n`:** não contam para a quota
- **Escopo típico:** mineração, prospecção, geologia e progressão subterrânea
- **Mínimo por nó-base:** 2 opções à esquerda + 2 à direita + 3 metamorfoses

Abilities de mods diferentes devem passar por adapters; nenhuma árvore pode ficar estruturalmente desfavorecida por possuir menos hooks em um provider específico.
