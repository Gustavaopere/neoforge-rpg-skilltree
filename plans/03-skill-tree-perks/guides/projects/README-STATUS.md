# Estado desta coleção

Criada em 2026-08-30 para tornar RPG Skill Tree, Volcanoes, Enshrouded e Black Arcana fontes obrigatórias da auditoria de perks.

A coleção distingue explicitamente runtime canônico, implementação parcial, trabalho preparatório, planejamento e fail-closed. Os apêndices dos três guias temáticos não substituem os quatro dossiês nem a matriz cruzada.
