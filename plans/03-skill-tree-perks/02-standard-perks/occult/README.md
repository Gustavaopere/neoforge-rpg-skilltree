# OCCULT — Standard Perks

- **Range reservado:** `P10000–P10999`
- **Quota:** `N_standard` — obrigatoriamente igual às demais árvores
- **Escopo de design:** ocultismo, sangue, almas, pactos, maldições e poderes proibidos
- **Estado:** catálogo ainda não preenchido

## Regras locais

Cada perk desta pasta deve ter ownership OCCULT, requisitos explícitos, efeito implementável e identidade suficiente para justificar um nó. Bônus genéricos sem decisão de build devem ser evitados ou absorvidos pelo sistema de atributos quando isso for semanticamente correto.
