# AGILITY — Standard Perks

- **Range reservado:** `P2000–P2999`
- **Quota:** `N_standard` — obrigatoriamente igual às demais árvores
- **Escopo de design:** mobilidade, precisão, evasão, cadência e posicionamento
- **Estado:** catálogo ainda não preenchido

## Regras locais

Cada perk desta pasta deve ter ownership AGILITY, requisitos explícitos, efeito implementável e identidade suficiente para justificar um nó. Bônus genéricos sem decisão de build devem ser evitados ou absorvidos pelo sistema de atributos quando isso for semanticamente correto.
