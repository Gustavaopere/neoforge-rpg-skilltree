# SUMMONING — Standard Perks

- **Range reservado:** `P9000–P9999`
- **Quota:** `N_standard` — obrigatoriamente igual às demais árvores
- **Escopo de design:** invocações, companions, servants, familiars e comando
- **Estado:** catálogo ainda não preenchido

## Regras locais

Cada perk desta pasta deve ter ownership SUMMONING, requisitos explícitos, efeito implementável e identidade suficiente para justificar um nó. Bônus genéricos sem decisão de build devem ser evitados ou absorvidos pelo sistema de atributos quando isso for semanticamente correto.
