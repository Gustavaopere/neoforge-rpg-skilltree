# ARCANE — Standard Perks

- **Range reservado:** `P5000–P5999`
- **Quota:** `N_standard` — obrigatoriamente igual às demais árvores
- **Escopo de design:** conjuração, magia, escolas/afinidades, mana e modificação de spells
- **Estado:** catálogo ainda não preenchido

## Regras locais

Cada perk desta pasta deve ter ownership ARCANE, requisitos explícitos, efeito implementável e identidade suficiente para justificar um nó. Bônus genéricos sem decisão de build devem ser evitados ou absorvidos pelo sistema de atributos quando isso for semanticamente correto.
