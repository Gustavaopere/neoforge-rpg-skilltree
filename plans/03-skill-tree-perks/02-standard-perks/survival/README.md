- **Quota:** `N_standard` — obrigatoriamente igual às demais árvores
- **Escopo de design:** sobrevivência, ambiente, exploração, caça e adaptação

## Regras locais

Cada perk desta pasta deve ter ownership SURVIVAL, requisitos explícitos, efeito implementável e identidade suficiente para justificar um nó. Bônus genéricos sem decisão de build devem ser evitados ou absorvidos pelo sistema de atributos quando isso for semanticamente correto.
