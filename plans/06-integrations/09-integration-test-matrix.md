# Integrations Plan — Compatibility Test Matrix

**Goal:** provar que adapters são opcionais e combinam sem duplicar ações.

- [ ] Testar cada mod suportado isoladamente.
- [ ] Testar ausência individual de cada mod opcional.
- [ ] Testar combinações críticas: Iron's + Ars, Epic Fight + magia/projéteis, morphs + classes.
- [ ] Executar dedicated-server smoke nas composições prioritárias.
- [ ] Registrar incompatibilidades conhecidas e versão mínima/máxima quando necessário.
- [ ] Garantir uma concessão de progressão por ação em cada combinação.

**Acceptance:** matriz reproduzível demonstra que presença/ausência de adapters não quebra o core nem duplica progressão.
