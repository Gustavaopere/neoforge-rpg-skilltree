- [ ] eventos semânticos reais alimentam mastery;

- [ ] documentação diferencia `IMPLEMENTED`, `PARTIAL`, `SPEC/DATA` e `PLANNED`;
- [ ] dedicated server inicia com combinações sem cada integração.
