# Data/UI Plan — Skill Tree Screen

**Goal:** tornar a árvore 512-node navegável e compreensível sem esconder requisitos.

- [ ] Pan e zoom estáveis em diferentes resoluções/UI scales.
- [ ] Tooltips com nome, descrição, rank, custo, requisito e efeito.
- [ ] Feedback claro para compra/respec negados.
- [ ] Mostrar confluências, bridges e pontos faltantes.
- [ ] Diferenciar visualmente caminho, gateway, capstone e nó comprável quando necessário.
- [ ] Manter cliente incapaz de conceder unlock localmente.

**Acceptance:** jogador consegue descobrir por que um nó está bloqueado e confirmar o resultado de uma compra sem ambiguidade.
