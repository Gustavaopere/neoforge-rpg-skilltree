# Data/UI Plan — Localization and Accessibility

**Goal:** manter todo conteúdo player-facing localizado e legível.

- [ ] Cobrir nomes, descrições, erros, gateways, classes e escolhas com chaves de lang.
- [ ] Evitar depender apenas de cor para transmitir estado.
- [ ] Garantir contraste/tooltip suficiente nas principais escalas de UI.
- [ ] Usar localização como fonte factual para geração da wiki quando apropriado.
- [ ] Validar chaves ausentes e placeholders inconsistentes.

**Acceptance:** nenhuma feature do escopo final exige ler ID cru para ser entendida pelo jogador.
