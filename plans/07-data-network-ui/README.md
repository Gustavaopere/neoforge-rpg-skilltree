# 07 — Data, Network & UI

Estado: **EM ANDAMENTO**.

## Objetivo
Dar ao jogador uma visão coerente de árvore, requisitos, nível, mastery e classes sem transferir autoridade para o cliente.

## Escopo
- loaders/validation de datapack;
- snapshots de progressão;
- packets mínimos;
- UI de árvore e detalhes;
- feedback de requisitos bloqueados;
- reload seguro.

## Critérios de aceite
- [ ] payloads têm limites e validação;
- [ ] reload não deixa referência órfã;
- [ ] UI representa o estado confirmado pelo servidor;
- [ ] erros de datapack indicam ID/caminho problemático.
