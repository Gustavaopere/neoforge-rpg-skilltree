# Quest Hooks Plan — Canonical Rewards

**Goal:** permitir recompensas de quest sem criar um segundo sistema de progressão.

- [ ] Conceder XP por serviço canônico.
- [ ] Conceder mastery somente quando a regra narrativa permitir e por API explícita.
- [ ] Conceder pontos/unlocks apenas por comandos autorizados.
- [ ] Validar caps e IDs antes da mutação.
- [ ] Emitir sync/eventos normais do core após reward.

**Acceptance:** reward de quest produz exatamente o mesmo estado que uma concessão equivalente feita pelo core.
