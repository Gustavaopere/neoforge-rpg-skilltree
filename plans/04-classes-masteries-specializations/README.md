# 04 — Classes, Masteries & Specializations

Estado: **EM ANDAMENTO**.

## Objetivo
Classes emergem do investimento/uso do jogador em vez de locks rígidos; masteries registram prática real e especializações adicionam identidade transversal.

## Contratos
- classe não substitui atributos/perks;
- mastery deve vir de eventos confirmados;
- gateways podem exigir classe + mastery + perk;
- especialização externa deve degradar graciosamente quando o mod alvo não existe.

## Critérios de aceite
- [ ] cálculo de classe determinístico;
- [ ] mastery não pode ser farmada por eventos cancelados/falsos;
- [ ] unlocks cruzados têm mensagens de requisito claras;
- [ ] Create/AE2 permanecem `SPEC/DATA` até adapter runtime comprovado.
