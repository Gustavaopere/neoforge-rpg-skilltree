# Classes Plan — Dedicated Class Subtrees

**Goal:** fechar árvores próprias de classes que têm progressão interna além do reconhecimento da identidade.

- [ ] Technomancer: revisar gateways Create/AE2/Oritech, caminhos e capstone.
- [ ] Warlock: validar cinco pactos, exclusividade e reselection/respec.
- [ ] Druid: validar formas naturais e permissões associadas.
- [ ] Metamorph: validar formas humanoides/monstruosas/aberrantes e blacklist.
- [ ] Garantir localização, requisitos e node effects coerentes em cada subtree.
- [ ] Testar respec e perda de requisitos de classe.

**Acceptance:** cada subtree abre somente para a identidade correta e nenhum efeito/permissão permanece órfão após perda do requisito.
