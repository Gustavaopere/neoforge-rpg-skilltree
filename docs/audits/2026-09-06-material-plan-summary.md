# Universal Material Chemistry — Executive Summary

The project will audit the entire canonical modlist, identify every material-bearing provider, classify all candidate materials, and build a canonical cross-provider catalog. Real materials receive only evidence-backed scientific formulae/structures/compositions. Fictional materials receive explicitly fictional arcane/runic signatures instead of fabricated chemistry. Hybrid materials preserve real and fictional parts separately.

Destroy 0.4.1 remains the chemical authority. The new subsystem maps exact identities and augments presentation without duplicating reactions, mixtures, hazards, or species. Molecule Drawings/Molecules is a visual inspiration source only; any source/data reuse requires exact license/provenance review.

Completion requires pack-wide audit coverage, catalog/Destroy drift gates, client/server-safe rendering, integration with existing RPG/Volcanoes inspection surfaces, green tests/CI, merge to main, and post-merge main verification.
