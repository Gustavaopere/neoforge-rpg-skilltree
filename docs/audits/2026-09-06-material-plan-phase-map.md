# Universal Material Chemistry — Phase Map

## Phase A — Audit foundation
Tasks 1–10: freeze modlist, taxonomy, catalog, provider boundary, Destroy contract, pack-wide material inventory.

## Phase B — Visualization
Tasks 11–14: pure render models, molecule/polymer structures, composition charts, arcane signatures.

## Phase C — Player-facing integration
Tasks 15–17: tooltips, existing encyclopedia/compendium, optional JEI integration.

## Phase D — Hardening and release
Tasks 18–20: drift detection, client/server/performance/full-pack validation, provenance, CI, merge, post-merge confirmation.

A phase cannot be declared complete while its required coverage tests are red or its blockers are undocumented.
