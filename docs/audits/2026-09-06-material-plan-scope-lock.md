# Universal Material Chemistry — Scope Lock

## In scope

- audit every mod in the canonical modlist for material-provider relevance;
- enumerate and classify material candidates from provider evidence;
- build canonical material identities and provider aliases;
- preserve real chemistry exactly where supported by evidence;
- preserve Destroy authority and add exact mappings only;
- scientific visualization for real elements, molecules, minerals, alloys, mixtures, and polymers;
- arcane/runic visualization for fictional materials;
- split scientific + arcane representation for hybrid materials;
- tooltips and existing encyclopedia/compendium integration;
- JEI integration only if the installed API exposes a stable extension point;
- automated provider/catalog/Destroy drift detection;
- provenance, license, CI, client/server, dedicated-server, full-pack, merge, and post-merge gates.

## Out of scope unless separately approved

- changing provider recipes or material balance;
- replacing Destroy reactions/mixtures/hazards;
- creating fake chemical species for fictional materials;
- adding GregTech/GTCEu as a dependency;
- inventing mineral chemistry from item names;
- automatically assigning historical rune meanings to fictional materials;
- rebuilding the RPG encyclopedia as a separate UI.
