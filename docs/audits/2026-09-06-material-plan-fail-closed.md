# Universal Material Chemistry — Fail-Closed Rules

The implementation must stop or locally disable a feature instead of guessing whenever evidence is insufficient.

- Unknown provider identity -> no canonical alias.
- Unknown real composition -> no scientific formula/composition display.
- Unknown Destroy identity -> no Destroy mapping.
- Unknown third-party license -> no copied code/data.
- Unknown JEI/encyclopedia hook -> no speculative integration.
- Missing fictional signature -> material remains blocked for arcane representation.
- Invalid resource reload -> retain last valid catalog.
- Optional provider adapter failure -> disable that adapter and report diagnostics.
- Client-only class detected in common bootstrap -> fail validation and do not merge.

Blocked states are first-class audit results, not errors to hide.
