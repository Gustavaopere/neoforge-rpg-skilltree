# Universal Material Chemistry — Source Policy

Provider identity and scientific truth are separate evidence questions.

For each real material, record both when applicable:

- **provider evidence**: proves what the mod resource is intended to represent;
- **scientific evidence**: proves the real-world formula/composition/structure displayed.

Preferred order for provider evidence:

1. exact installed-version source/data/API;
2. official project documentation;
3. maintainer-authored release/documentation material.

Preferred order for scientific evidence:

1. recognized chemical/mineralogical standards or databases;
2. primary/reference literature;
3. authoritative institutional references.

Search snippets, item names, recipe ingredients, Ore/Item tags, and visual resemblance are discovery hints only and cannot alone prove chemical identity.
