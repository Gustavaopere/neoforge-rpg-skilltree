# Universal Material Chemistry — Destroy Coverage Policy

Destroy coverage is version-bound to the installed 0.4.1 NeoForge port.

The implementation must first prove whether the installed runtime exposes a complete enumerable set of chemical identities.

If complete enumeration is proven:

`Destroy coverage = mapped/renderable enumerable Destroy identities / total enumerable Destroy identities`

The release target is 100%, enforced by automated comparison.

If complete enumeration is not proven:

- do not claim 100% of Destroy;
- document the exact verified boundary;
- test 100% of that boundary;
- record the technical limitation preventing complete enumeration.

No bridge may fabricate or duplicate a Destroy species merely to increase the coverage percentage.
