# Universal Material Chemistry — Provider Audit Order

Preferred audit order for implementation reviewability:

1. Destroy/Petrolpark ecosystem.
2. Volcanoes, RNS, TFC and other geological/mineral providers.
3. Create metallurgy/petrochemical/industrial addons including TFMG and related providers present in the canonical modlist.
4. Other technology mods adding metals, alloys, chemicals, fuels, gases, polymers or feedstocks.
5. Magic mods adding gems, essences, fictional metals/crystals/materials.
6. Worldgen/adventure/content mods adding ores, minerals, gems or material drops.
7. Remaining consumer-only and no-material mods to close 100% canonical modlist audit coverage.

Each provider family should end with catalog validation, coverage tests, audit updates and a reviewable commit set before advancing.
