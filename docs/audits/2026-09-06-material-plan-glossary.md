# Universal Material Chemistry — Glossary

- **Canonical material**: project identity representing one proven material across one or more provider resources.
- **Provider reference**: item/fluid/material identity owned by another mod.
- **Exact alias**: provider reference proven to represent the same canonical material.
- **Scientific representation**: real formula, structure, or composition backed by evidence.
- **Arcane signature**: explicitly fictional runic/sigil representation with no claim of chemical meaning.
- **Hybrid material**: provider-defined material containing both real and irreducibly fictional constituents.
- **Destroy native**: identity already owned by Destroy's chemistry model.
- **Display only**: material may be represented visually but is not injected into Destroy chemistry.
- **Blocked**: evidence or technical contract insufficient for safe support.
- **Coverage boundary**: exact set over which a percentage claim is valid.
