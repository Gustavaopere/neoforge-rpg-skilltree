# Universal Material Chemistry — Catalog Rules

1. One canonical identity may have many provider aliases when equivalence is proven.
2. One provider reference may belong to only one canonical identity.
3. Real materials require scientific provenance before support.
4. Fictional materials forbid scientific formula fields.
5. Hybrid materials keep real and fictional representations separate.
6. Destroy native/exact aliases are real only and require installed-version evidence.
7. Minerals use mineralogical/empirical representation, not fake molecules.
8. Alloys use composition/ranges, not fake molecules.
9. Mixtures always label their fraction basis.
10. Polymers never invent chain length.
11. Unsupported or ambiguous candidates remain blocked.
12. Catalog reload is atomic; invalid new data must not replace the last valid catalog.
