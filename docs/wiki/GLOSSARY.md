# Glossário

**Attribute** — valor RPG base/derivado usado por sistemas e perks.

**Bridge** — nó ou adapter que conecta domínios de progressão/sistemas.

**Class** — identidade emergente calculada a partir da construção/progressão do personagem.

**Gateway** — conjunto de requisitos que libera uma ação, perk ou sistema.

**Mastery** — proficiência adquirida por uso confirmado de um domínio.

**Node effect** — operação declarativa aplicada por uma skill/perk.

**Perk / skill node** — unidade desbloqueável da árvore.

**Relevant player level** — nível de jogador considerado pelo algoritmo de scaling para uma entidade/contexto.

**Specialization** — identidade/progressão mais específica, interna ou associada a um ecossistema de mod.

**Server-authoritative** — o servidor valida e decide estado de gameplay; o cliente não é fonte de verdade.

**SPEC/DATA** — conteúdo definido em documentação/datapack sem prova suficiente de adapter runtime completo.
