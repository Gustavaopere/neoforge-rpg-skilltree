# 05 — Facções, Ideologias e Instituições

Cada facção relevante recebe `FAC-####`.

Registrar:
- objetivos públicos e privados;
- ideologia;
- estrutura e liderança;
- conhecimento/evidências;
- recursos/influência;
- relações com outras facções;
- posições sobre necromancia, vampirismo, magia proibida, indústria, Shroud, Black Arcana, automação etc.;
- possíveis mudanças internas;
- critérios de ruptura, aliança, sucessão e dissolução.

Reputação com o jogador deve ser multidimensional quando o conteúdo exigir.
