# Quests Emergentes

Conteúdo gerado a partir do estado real do mundo: necessidades, conflitos, relações, recursos, ameaças, leis e eventos.

Regras:
- não contradizer cânone;
- não inventar mecânica de mod/provider;
- não conceder recompensas fora dos pipelines canônicos;
- não criar segredo que todos sabem automaticamente;
- respeitar actors mortos/ausentes/sem knowledge;
- preferir problemas locais e consequências sistêmicas;
- permitir expiração, transformação ou resolução sem o jogador.

IA pode auxiliar na autoria desse conteúdo, mas o Narrative Core valida fatos e consequências.
