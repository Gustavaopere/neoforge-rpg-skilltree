# 04 — Quests e Oportunidades

Subpastas previstas:
- `principais/`
- `secundarias/`
- `companheiros/`
- `faccoes/`
- `assentamentos/`
- `emergentes/`
- `ocultas/`

Uma `QST-####` representa uma oportunidade narrativa, não necessariamente uma entrada visível no journal.

Toda quest significativa deve declarar eixos ortogonais de:
- availability;
- discovery;
- engagement;
- resolution.

O FTB Quests é apresentação/journal; não é autoridade do estado narrativo.
