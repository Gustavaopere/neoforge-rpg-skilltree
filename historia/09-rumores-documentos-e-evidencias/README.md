# 09 — Rumores, Documentos e Evidências

Use `EVD-####` para peças narrativas que transportam conhecimento relevante.

Tipos incluem:
- rumor;
- depoimento;
- carta;
- livro;
- registro técnico;
- cadáver/vestígio;
- objeto;
- estrutura;
- marca física;
- gravação/registro;
- documento institucional.

Cada peça deve declarar:
- o que pode provar;
- o que apenas sugere;
- quem pode conhecer;
- confiabilidade;
- origem/proveniência;
- possibilidade de falsificação/destruição/perda;
- quais fatos ela não prova.
