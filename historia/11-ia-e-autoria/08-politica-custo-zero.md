# Política de Custo Zero para Autoria

## Estado
OBRIGATÓRIO para o fluxo recomendado de autoria.

## Regra principal
O desenvolvimento narrativo deve continuar funcional sem assinatura adicional, compra de créditos, API paga ou trial que expire.

## O que conta como custo aceitável

- ferramenta open-source executada localmente;
- serviço realmente gratuito sem necessidade de cartão;
- recurso já incluído no ambiente atual do projeto, desde que seu uso não gere cobrança adicional;
- software gratuito como Blockbench, Ink/Inky e editores livres.

## O que não conta como solução gratuita

- trial com prazo;
- créditos promocionais que acabam;
- plano gratuito insuficiente para manter o fluxo normal;
- serviço que exige chave de API paga para a função essencial;
- ferramenta gratuita apenas para visualizar, mas paga para exportar o resultado necessário;
- integração que exige contratar infraestrutura externa apenas para permanecer online.

## Procedimento quando uma ferramenta muda de preço

1. congelar novas dependências nela;
2. exportar dados em formato aberto;
3. continuar usando os arquivos canônicos do GitHub;
4. buscar substituto gratuito/open-source;
5. remover a ferramenta do fluxo recomendado se a substituição for suficiente.

## Regra de portabilidade
Toda ferramenta auxiliar deve trabalhar com cópia derivada ou exportável. O material canônico continua em formatos versionáveis no repositório.

## Preferência atual

1. GitHub + ChatGPT para autoria e revisão;
2. Blockbench para skins e validação visual;
3. Markdown para fichas e diálogos enquanto for suficiente;
4. AIStoryHub somente em modo gratuito;
5. Ink/Inky quando branching complexo justificar;
6. MCPs local-first/open-source como fallback em clientes compatíveis.

## Revisão temporal
Preços e planos mudam. Antes de adotar qualquer serviço externo, verificar novamente as condições vigentes e registrar a data da verificação no PR correspondente.
