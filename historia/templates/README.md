# Templates narrativos — legado de migração

Os arquivos deste diretório são snapshots históricos/compatibilidade do período anterior à migração da capability de autoria narrativa.

A authority para scaffolds narrativos reutilizáveis é `Gustavaopere/minecraft-mod-factory/narrative/templates/`.

Regras:

- não criar novos templates genéricos neste diretório;
- não evoluir os snapshots locais como uma segunda linha de templates;
- para nova autoria, consumir a versão da Factory e aplicar `historia/narrative-authoring-profile.json` quando necessário;
- conteúdo e contratos específicos da campanha continuam em `historia/`;
- os arquivos legados podem permanecer temporariamente para proveniência/compatibilidade até que uma remoção segura seja possível.

A presença de um arquivo legado aqui não lhe concede autoridade sobre a versão correspondente da Factory.
