# 08 — Eventos

Eventos narrativos usam `EVT-####` quando precisam de identidade editorial estável.

O runtime usa suas próprias replay/idempotency keys e Event Ledger; o ID editorial não substitui identidade técnica de ocorrência.

Eventos podem ser:
- históricos;
- únicos;
- recorrentes;
- emergentes;
- locais;
- globais;
- observados ou não observados pelo jogador.

O fato de o servidor conhecer um evento não concede knowledge automático aos personagens.
