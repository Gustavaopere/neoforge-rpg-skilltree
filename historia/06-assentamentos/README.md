# 06 — Assentamentos

Cada assentamento narrativamente relevante recebe `SET-####`.

MineColonies pode ser o provider físico de população, construções, profissões, raids e infraestrutura, enquanto o Narrative & Society Core mantém governo, leis, instituições, influência, opinião pública e segredos quando não existirem como authority nativa.

Registrar:
- governo;
- leis;
- instituições;
- composição/cohorts;
- influência;
- estabilidade;
- tolerâncias culturais;
- crises e memória histórica;
- relação com colônia/provider físico.
