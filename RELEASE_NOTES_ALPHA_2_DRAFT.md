# Alpha 2 — Progression Runtime Foundation (Draft)

Version target: `0.2.0-alpha.2`
Target: Minecraft 1.21.1 / NeoForge
Status: development branch; not released and not yet an installable JAR.

Alpha 2 turns the Alpha 1 architecture into a persistent progression model that can be wired to NeoForge and the selected modpack systems.

Current draft scope:
- Character Level 1-100 independent from vanilla XP;
- 1 passive point per Character Level;
- boss-point ledger with first-credit protection and configurable provider values;
- 11 main progression regions and 3/3/3 Final Triads;
- natural and abnormal class confluences;
- persistent class unlocks and bridge point spending;
- 24 seed classes and 25 post-class specializations;
- Warlock pact choices;
- Druid/Metamorph Morph gating contracts;
- Apothic sockets/gems/attributes integration contracts;
- target-node shortest-path planning;
- 512-node / 803-edge base tree blueprint.

This draft becomes a release only after the actual NeoForge runtime, persistence/networking, Passive Skill Tree UI/runtime integration, mod adapters, JAR build, and in-game tests are working.
